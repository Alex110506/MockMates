# 🚀 MockMates

**MockMates** is a social web application designed for students who want to **practice mock interviews** with peers.  
It provides a collaborative environment that combines **communication, coding, and learning** — all in one platform.

---

## 🌟 Features

### 👥 Social & Collaboration
- **Friends System** – connect with other users, send and accept friend requests.  
- **Chat System** – real-time messaging with support for text, files, and media.  
- **File Sharing** – securely share resumes, PDFs, or code snippets in chats.  
- **Video Chatting** – conduct live mock interviews with integrated video calling.  

### 💻 Coding & Collaboration
- **Real-Time Code Sharing** – collaborate on a shared coding environment (Google Docs–style) during video calls.  
- **VS Code–Like Syntax Highlighting** – provides a familiar coding experience for users.  

### 🌍 Smart Networking
- **Location-Based Friend Recommendations** – discover potential mock partners nearby using location data.  

### 🔜 Upcoming Features
- **DSA Practice Page** – curated data structures and algorithms questions for interview preparation.  
- **System Design Section** – explore and discuss large-scale architecture problems.  

---

## 🧠 Tech Stack

### 🖥️ Frontend
- **React** – component-based UI for a seamless user experience.  
- **Tailwind CSS** – modern utility-first styling for rapid design.  
- **TanStack Query** – efficient data fetching and state management.  
- **Stream** – handles chat, messaging, and scalability with robust real-time APIs.

### ⚙️ Backend
- **Node.js** – fast and scalable server environment.  
- **Express.js** – clean and organized backend structure with RESTful routes.
- **MongoDB** – NoSQL database for storing users, chats, and relationships.  
- **Mongoose** – elegant ODM for managing MongoDB schemas and data models.  

---

## 🧩 Architecture & Design
MockMates follows a **modular and maintainable architecture**, ensuring scalability and clean separation of concerns.  
Key principles:
- **Reusable Components** – UI and logic split into independent modules.  
- **API-Centric Design** – front and back communicate via clean REST APIs.  
- **Real-Time Communication** – powered by Stream for low-latency updates.  
- **Scalable Structure** – optimized for future growth (DSA & System Design modules).  

---

## 🎯 Purpose
MockMates aims to **make interview preparation social, interactive, and engaging**.  
Students can practice technical interviews together, share code, communicate seamlessly, and build confidence through peer learning.

## ⚡ Start the App

Clone the repository, then run the following commands:

```bash
# Build both frontend and backend
npm run build

# Start the backend server
npm run start
```
